## `1D09:03C2` procedure (`0x1D452`–`0x1D50D`)

**Stack:** `[bp+6]` escorter index, `[bp+8]` target linear loc, `[bp+0Ah]` radius `n`.

**Pre-loop (deterministic):**

1. `ax = [bp+8]`; `idiv 100` → `baseQuot = ax - n` at `[bp-2]`, `baseRem = dx - n` at `[bp-4]` (DOS `loc = quot·100 + rem`; Empirata **`y·100+x`** → first draw is **Y**, second is **X**).
2. `divisor = 2*n + 1` at `[bp-0Eh]` (`shl n; inc`).

**Loop:** `[bp-0Ah] = 0x14` (20). Head `0x1D489`: decrement; exit at 0 when exhausted (`0x1D500`, `ax = 0`).

Per iteration (`0x1D493`–`0x1D4F0`):

| Step | Instruction | Effect |
|------|-------------|--------|
| 1 | `call 25E6:0F64` → `0x26DC4` | `rand15` in `AX` (15-bit, `AH &= 0x7F`) |
| 2 | `cwd`; `idiv [bp-0Eh]` | **`tileY = (AX % divisor) + baseQuot`** → `[bp-6]` (imul leg) |
| 3 | `call 25E6:0F64` | second draw |
| 4 | `cwd`; `idiv [bp-0Eh]` | **`tileX = (AX % divisor) + baseRem`** in `DI` |
| 5 | Clamp imul leg | `[1, 0x3A]` (58) → Empirata **Y** |
| 6 | Clamp add leg | `[1, 0x62]` (98) → Empirata **X** |
| 7 | `SI = Y*100 + X` | linear index (`imul 100`, `add X`) |
| 8 | `push SI`; `push [bp+6]`; `call 1A9E:006C` | reachability |
| 9 | If `AX != 0` | **return `SI` in `AX`** (`0x1D4F2`–`0x1D4FF`) |
| 10 | Else | next iteration |
