# Mapgen preview artifacts

Generated by `node scripts/preview-organic-maps.mjs` after `npm run build`.

- `*-ellipse.txt` / `*-organic.txt` — ASCII land (`#`) / sea (`.`)
- `*.pgm` — portable graymaps for quick visual diff
- `summary.json` — land fraction / component / playability summary

Large text/PGM files are gitignored; regenerate locally when comparing generators.
